# Roadmap

Version 1.2 includes one persistent living pet, free following/fetch/food play, five selectable worlds with lighting/weather, purchased decorations, three permanent adventures, seven earned badges, four games, a daily trio, JSON backup/recovery and Turkish/English controls. Version-1 saves migrate forward with old progress retained.

Next work should start with the physical Touch Bar checklist and a measured keyboard/VoiceOver pass. Keep real device results separate from native callback acceptance.

Further candidates, not shipped: an explicitly opted-in launch-at-login setting, several independently backed-up pets, more interactive scene objects, adjustable low-pressure round lengths and Apple Developer ID/notarized distribution. Preserve both CPU families and explicit save migrations. Avoid compulsory streaks, surprise background behavior or imaginary adoption metrics.
