# Roadmap

Version 1.1 includes one persistent pet, gradual touch following, automatic walks, ball/bone fetch, food placement and timed eating, free care, a transparent coin/XP progression, daily trio, three shared strip games, local backup recovery and Turkish/English controls.

Next work should start with the physical Touch Bar checklist and a measured keyboard/VoiceOver pass. Keep real results separate from native callback acceptance.

Further candidates, not shipped: an explicitly opted-in launch-at-login setting, additional habitats earned through play, several independently backed-up pets, adjustable low-pressure round length and Apple Developer ID/notarized distribution. Preserve both CPU families and backward-compatible save migrations before adding those features. Avoid compulsory streaks, surprise background behavior or imaginary adoption metrics.
